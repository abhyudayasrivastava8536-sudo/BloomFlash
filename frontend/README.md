# BloomFlash storefront

React, TypeScript, Vite and Tailwind customer experience for the BloomFlash flower and circular-reuse platform. For full setup, run instructions and API notes, see the repository [README](../README.md).

```bash
npm install
npm run dev
```

The Vite development server is at `http://localhost:8080` and proxies `/api` to `http://localhost:5000`. Set `VITE_API_URL` in `.env` to use a deployed API.
